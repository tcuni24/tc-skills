# 方法说明文档骨架与共通措辞

适用于随结果表一起交付的「<对象><主题>方法与结果说明.docx」。同一客户的多份说明使用同一骨架；
三级小节按各自流程展开，参数不同处照实写。

## 封面

```
<物种中文名>（<拉丁名>）<主题>          ← 标题
方法、参数与结果说明                    ← 副标题
——<一句话流程摘要>                      ← 可选
```

封面和正文不放「文中黄色高亮为待核对信息」这类草稿提示。

## 章节骨架

| 章 | 内容要点 | 常用表 |
|---|---|---|
| 1 概述 | 第一段：研究对象、材料、目的；整体流程用「→」串起来。第二段：最终交付多少个、关键结论，以及「本次更新……，更新内容见附录」 | 表 1 分析流程总览（步骤 / 内容 / 软件或方法 / 数量变化） |
| 2 材料与数据 | 2.1 参考基因组（版本、序列数、总长、公开下载来源）；2.2 其他基因组或测序材料 | 基因组表 / 各材料测序与比对统计 |
| 3 分析方法与参数 | 每个流程步骤一节，标题写「做什么（软件）」；每节先一句话说明目的，再列影响结果的参数 | 参数表、过滤阈值表、指标定义表 |
| 4 结果汇总 | 筛选漏斗（每步数量能前后算平）、主要统计 | 结果汇总表 |
| 5 交付文件与字段说明 | 5.1 交付文件（文件名 / 内容）；5.2 结果表字段（与 xlsx「说明」页同源） | 交付文件表、字段表 |
| 6 使用建议与注意事项 | 共通条目 + 物种 / 流程特有条目 | — |
| 7 软件与版本 | 用途 / 软件 / 版本；版本取自实际运行环境，取不到写「—」 | 使用的软件 |
| 参考文献 | 软件原始文献，悬挂缩进 | — |
| 附录 本次更新内容 | 与上一版交付的差异：新增、改名、更正的数值（写明受影响数量）、未变的部分 | — |

## 共通措辞（逐字复用，按项目替换尖括号）

使用建议：

- 产物大小为基于<公开基因组序列 in-silico PCR / 重测序基因型>推算的理论值，未经 PCR/毛细管电泳实测。荧光标记、引物尾巴序列及电泳迁移率差异会使实测值与预测值存在数 bp 的系统偏移，建议设置已知材料作内参校准，并先选少量位点做实验验证。
- 二核苷酸位点 PCR 过程中 stutter 条带明显，毛细管电泳判读时请注意区分主峰与 stutter 峰；条件允许时优先选用三、四核苷酸位点。
- 若实测大小与预测不符，欢迎反馈，我们将据此核查该位点的<基因组序列 / 基因型>与引物。

附录首条写新增内容，第二条写「……均不变」，让客户知道哪些可以沿用。

## 术语与格式

| 统一为 | 不用 |
|---|---|
| 重复次数 | 重复数、拷贝数（指 SSR 重复单元时） |
| 单纯型 / 复合型 SSR | 简单 / 复杂 SSR 混用 |
| 特异 / 非特异 | Specific 与「特异」混用（沿用上一版原值时在正文注明对应关系） |
| 引物 Tm | 退火温度（Primer3 参数是 Tm） |
| 送检材料、提供的 N 个标记位置 | 客户提供的…… |
| 数值范围「10–20」 | 10~20、10--20 |
| 全角标点（，；：（）） | 中文句中的半角 , ; : ( ) |
| 百分比 1 位小数（78.8%） | 位数不一 |

结果表列名用英文 snake 风格并跨交付统一：`<样本>_size_bp`、`ref_size_bp`、`size_min_bp`、`size_max_bp`、
`size_diff_bp`、`size_allele_num`、`<样本>_repeat`、`allele_num`、`maf_like`、`missing_count`。
列说明只写一份，docx 字段表和 xlsx「说明」页都从它生成。

## 去内部信息清单

检查脚本会拦截前四类；后几类需要人工读。

| 类别 | 例子 | 处理 |
|---|---|---|
| 本地路径 | `/data_0/...`、`/project/...` | 删除 |
| 内部文件 / 脚本名 | `genome.fa`、`*.sorted.bam`、区域 BED、VCF 名、`filter_*.py` | 改为描述（「参考基因组」「比对结果」）；交付文件名和公开下载文件名保留 |
| 运行细节 | GPU 型号、线程数、`-num_threads`、`-outfmt` 字段串 | 删除；与结果有关的写「GPU 加速版」 |
| read group 占位值 | `LB=lib1`、`PL=ILLUMINA` | 删除整段 read group 说明；平台以实际测序平台为准 |
| 第三人称 | 「客户提供的」 | 改为「提供的」「送检」 |
| 草稿痕迹 | 高亮、「待核对」、「请告知」挂在方法正文 | 删除；需要客户确认的事放「使用建议」 |
| 内部转换细节 | 坐标系换算、中间表格式 | 只写对结果判读有用的结论 |
