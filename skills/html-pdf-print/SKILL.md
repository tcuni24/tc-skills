# HTML 报告打印优化

以实际生成的 PDF 为验收对象。HTML 正常、CSS 含有 `break-inside`、浏览器进程退出成功，都不足以证明分页正确。

## 先明确打印契约

从用户要求和现有项目中确定目标浏览器/打印引擎、纸张、缩放，以及页脚是**每页重复**还是**仅末页底部**。已有明确选择就沿用；只在缺失信息会改变实现时询问。区分报告自己的页脚与浏览器自动添加的日期、URL、页码。

A4、100% 缩放、上下 12mm 是本方法的一组已验证参数，不是所有报告的要求。保留现有页面内容和屏幕阅读方式，把变更放在报告模板与打印层。

## 建立可复现的打印样本

- 使用生产渲染入口与有效数据，至少包含可解码的真实图片；长图、横图、长表及跨页临界处的短说明尤其有价值。`write_bytes(b"image")` 之类占位文件只会测试缺图回退。
- 冻结同一份数据和图片，保存修改前 PDF。用文字坐标、同段首尾/表格行所在页、图片出现情况和页脚位置，建立能在当前问题上失败的检查，再逐项修复。
- 图片与字体加载完成后才打印。屏幕截图或单纯 `emulateMedia('print')` 尚未执行分页；必须实际调用打印/PDF 导出。
- 浏览器启动受限时，按当前权限机制使用已获授权的运行环境；缺依赖/被拒绝应记录为阻断，不能把 skipped 或静态样式检查说成打印通过。临时文件位置和重任务调度沿用当前环境规则。

需要命令和坐标检查时，读取 [references/pdf-validation.md](references/pdf-validation.md)。随附 `scripts/check_pdf.py` 只检查 PDF 几何与可选页底文案，不修改文件。

## 按证据调整分页

| PDF 中的症状 | 优先验证的原因与调整 |
| --- | --- |
| 新页首行/标题被切掉、文字贴纸边 | 检查最终生效的 `@page`；为每页留真实页边距，而不是只给整篇报告加 padding。合并相互覆盖的页设置。 |
| 短说明末行单独落到下一页 | 小型说明块 `break-inside: avoid`；段落 `orphans` / `widows`；标题 `break-after: avoid`。先验证发生问题的块，不给整章套不可拆。 |
| 整章被推走或大片空白 | 长章允许分页；移除无内容的强制换页元素、无必要的固定高度。超一页的块不可能靠 `avoid` 保持整块。 |
| 图和说明分离、长图截断 | 保持能容纳一页的图卡完整；按可打印高度扣除标题、说明、图注和间距后限制图片高度，保持纵横比；多图卡允许在子图之间分页。 |
| 表格续页难读或缺行 | 使用真实 `thead`，保护能放进一页的行；检查滚动/裁切容器是否影响打印。逐页核对表头及行首尾，超长行需允许拆分。 |
| 不同屏幕宽度打印结果不同 | 排查未限定 `screen` 的响应式覆盖、打印中的隐藏面板/语言切换；在实际纸张宽度与窄屏入口复核。 |

以上是诊断方向；仅修改已复现的问题。PDF 页数增加可能是安全留白或保护内容完整的代价，不能只按页数评价效果。

## 单独处理页脚语义

每页重复与仅末页是不同实现。前者可评估目标引擎支持的页边距盒或固定页脚，并预留正文空间。后者不能直接套用重复页脚，也不能用 `scrollHeight / 页高` 估算余量——原生避分页和表头重复会改变实际分页。

当用户需要**仅末页底部**、目标是可控尺寸的 Chromium 打印时，读取 [references/last-page-footer.md](references/last-page-footer.md)：它给出同尺寸分栏测量的实现范式、打印媒体事件时序和适用边界。其他引擎先验证能力，不强行移植。

## 验收与交付

用修改前相同样本生成修改后 PDF，并检查：

- 文字位于纸张安全区；短说明、标题和图卡保持应有联系；长表内容无丢失、续页表头可见。
- 图片完整，页脚次数、所在页及离底部距离符合契约；没有遮挡正文或多出只有页脚的空页。
- 至少覆盖不同正文长度；涉及脚本时检查重复打印、取消/结束后的屏幕恢复、测量节点清理与脚本错误。涉及多语言、分组图时覆盖对应可见状态。
- 查看栅格化 PDF 的问题页、图表页和末页。文字提取不能发现所有图像裁切、重叠和不可见内容。

把稳定检查接入项目已有测试入口；补充打印设置与重新生成 HTML 的说明。交付可查看的 PDF、实际执行的测试和未覆盖的引擎/设置。全量检查被既有问题阻断时，分别记录本次验证、基线复现证据和整改项，不宣称全量通过。
