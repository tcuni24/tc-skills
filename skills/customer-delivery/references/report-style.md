# 报告样式要点（摘自 /public/scripts/tc-design-md/probe.design.md，2026-09-18 基准）

`scripts/render_report.py` 已内置这套样式。这里只列内容层在写 JSON 时必须遵守的约束；
完整规范以 probe.design.md 为准。

## 阅读顺序

封面（logo → 体裁标签 → 标题 / 副标题 → 速览 `b-intro` → 元数据）→ 四格 KPI → 正文章节 → 附录 → 页脚。
屏幕有吸顶导航，打印隐藏。

- 速览先说"交付了什么、应关注什么"：一句话结论 + 规模。
- KPI 四格都要有数值、标签、口径三层；第四格是风险位（`watch: true`），成绩指标不要放这里。
- 数据不可用显示 `—` 并写原因，不能写 0 / 0%。

## 颜色语义

| 语义 | 用法 |
|---|---|
| 青绿 `#087f73` | 主数据、品牌强调；不表示"全部通过" |
| 蓝 `#2b6cb0` | 第二等级 / 第二类别 |
| 琥珀 `#9a7414` / 浅底 `#fff7ea` | 需关注、风险，配明确文字 |
| 珊瑚 `#b44b46` | 不合格 / 高风险，由业务判据决定 |
| 灰 + `—` | 无法判定、缺失 |

颜色必须同时配文字、数字或线型。等级、风险分档与普通分类是三种语义，不混用。

## 组件用法

- `conclusion` 答"结论是什么"，`watchbox` 答"结论适用到哪里"，两者分开。
- `note` 放口径补充，`note warning` 放需要注意的限制；限制放在对应答案之后。
- 表格只放判读所需列；文字列左对齐，数值列 `number: true` 右对齐。长明细留在 XLSX。
- 图表卡：一图一模块，`principle`（统计对象、坐标、口径）与 `interpretation`（本项目数据及限制）两栏；图注含单位 / 阅读指引；缺图显式占位。
- 构成条 `bars` 只在统计可用时渲染，pct 读已计算值，不在模板里再算。
- 原理示意图必须注明"示意，非本项目实测"。

## 科学图（plot_kit.plot_style）

- PNG 160 dpi，白底，无阴影渐变，轻水平网格，图例无边框。
- 主数据青绿；等级用青绿 / 蓝 / 琥珀 / 珊瑚身份色；分类用 PALETTE 明确映射。
- 计数千位分隔，比例带 %，单位写在轴标签。
- 中文标签先用 `plot_kit.cjk_font()` 检查字体；检查对象是 normal / semibold 实际解析到的字体文件和
  内部 family，而不只是候选字体名。名称为 SC 但实际打开为 JP / KR / TC / HK 区域字形的 TTC 不可用。
- `cjk_font()` 返回 `None` 时用英文标签和 `plot_style(cjk=False)`。`save()` 会检查可见中文文本（包括
  中文与全角标点）的实际字体与字形覆盖；交付前仍要目视核对 PNG，因为目录和报告审计脚本不识别栅格图里的地区字形。
- 常用画布：直方 / 条形 `(8.4, 5.2)`，环图 `(8.6, 5.0)`，染色体条形宽 8.2、高随行数增长。

## 打印

A4、内容留白 18mm、图卡整块不拆、章节自然跨页、不插空白分页。渲染器已处理；
内容层只需避免单张图卡里塞过长解释文字（超过一页会溢出）。

## 离线

不加载外部 CSS / 字体 / CDN；HTML + `plot/` 一起交付，搬到别的电脑能直接打开。
