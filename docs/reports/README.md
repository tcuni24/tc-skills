# Round reports

Historical execution records of `herdr-pair` pairing rounds (round 9 – 16), moved
here from `skills/herdr-pair/reports/` so they no longer ship inside the skill
package — `npx skills add tcuni24/tc-skills` installs only version-controlled
files, and these records are repository history, not skill content (see
`docs/reviews/2026-09-27-repo-assessment.md`, A5).

- `herdr-pair/round-N-report.md` — what each round changed, how it was verified,
  and what was deliberately left out.

The `reports/` paths inside those documents (and inside `SKILL.md` templates)
refer to the *paired project's* round reports, not to this directory.
